# Fusion: запуск и локальные ключи

Откройте существующую папку `Desktop/Fusion`. Если страница уже работает, повторно запускать серверы не нужно. После установки зависимостей команды не требуют доступа к внешним API.

Запуск одной командой после установки зависимостей:

```bash
cd ~/Desktop/Fusion
.venv/bin/python scripts/run_local.py
```

Уже работающие экземпляры останутся включёнными. Проверка без перезапуска: `.venv/bin/python scripts/run_local.py --check`. Ниже — отдельные команды для двух терминалов при разработке.

Терминал 1 — сервер:

```bash
cd ~/Desktop/Fusion
.venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

Терминал 2 — интерфейс:

```bash
cd ~/Desktop/Fusion
npm --prefix frontend run dev
```

В обычном браузере откройте http://127.0.0.1:5173. Не закрывайте запущенные процессы во время работы. Изменения frontend появляются автоматически. После изменений Python или данных перезапустите сервер в первом терминале и обновите страницу; не оставляйте сервер выключенным. Ошибка занятого порта обычно означает, что экземпляр уже работает.

## Файл backend/.env

Пример конфигурации; значения ключей заполните только у себя:

```dotenv
OPENAI_API_KEY=
OPENAI_MODEL=gpt-5.4-mini
NVIDIA_API_KEY=
NVIDIA_MODEL=nvidia/nemotron-nano-3-30b-a3b
NVIDIA_BASE_URL=https://integrate.api.nvidia.com/v1
NVIDIA_ENABLED=false
```

Откройте файл в редакторе и вставьте ключ после `=` в строке `OPENAI_API_KEY`. В чат, frontend, VITE-переменные и Git их не переносить. Файл исключён из Git; после клонирования на другом компьютере его создают отдельно. При работе Codex не выводить содержимое реального файла в инструменты или журналы.

Настройки загружаются backend при старте. После замены модели или ключа перезапустите backend. По решению команды NVIDIA выключена по умолчанию: оставленный в файле ключ не вызывает запросов. Для необязательной рецензии нужен действующий ключ NVIDIA API Catalog и явное `NVIDIA_ENABLED=true`.

Модель аналитика — [GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini) с уровнем рассуждения low. Она поддерживает Responses и Structured Outputs; практическая проверка проекта фиксируется в [AI_VALIDATION.md](AI_VALIDATION.md). Секреты не попадают в интерфейс или Git.

## Подготовка демо

Отсчёт лимита команды — примерно 15:49 Алматы 23 сентября 2026; дедлайн около 17:49. Основной сценарий — локальный граф, три CSV, объяснение OpenAI и ссылки на проверяемые факты. NVIDIA исключена из обязательного объёма по решению пользователя после ошибки доступа.

Перед выступлением выполните `--check`, откройте http://127.0.0.1:5173 и пройдите [DEMO.md](DEMO.md). Кеш AI хранится в памяти 1 час и исчезает при перезапуске; заранее откройте нужные примеры. Реальная проверка шести узлов: `.venv/bin/python -m backend.validate_ai` (платные запросы, только явно).
