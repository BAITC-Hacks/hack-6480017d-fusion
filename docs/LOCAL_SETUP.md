# Fusion: запуск и локальные ключи

Откройте существующую папку `Desktop/Fusion`. Если страница уже работает, повторно запускать серверы не нужно. После установки зависимостей команды не требуют доступа к внешним API.

Терминал 1 — сервер:

```bash
cd ~/Desktop/Fusion
.venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

Терминал 2 — интерфейс:

```bash
cd ~/Desktop/Fusion
npm --prefix frontend run dev
```

В обычном браузере откройте http://127.0.0.1:5173. Не закрывайте запущенные процессы во время работы. Изменения frontend появляются автоматически. После изменений Python или данных перезапустите сервер в первом терминале и обновите страницу; не оставляйте сервер выключенным. Ошибка занятого порта обычно означает, что экземпляр уже работает.

## Файл backend/.env

На текущем ноутбуке создан локальный `backend/.env` с пустыми ключами и стартовыми моделями:

```dotenv
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4.1-mini
NVIDIA_API_KEY=
NVIDIA_MODEL=nvidia/nemotron-3-nano-30b-a3b
NVIDIA_BASE_URL=https://integrate.api.nvidia.com/v1
```

Откройте файл в редакторе и вставьте ключи после `=` в двух строках `*_API_KEY`. В чат, frontend, VITE-переменные и Git их не переносить. Файл исключён из Git; после клонирования на другом компьютере его создают отдельно. При работе Codex не выводить содержимое реального файла в инструменты или журналы.

Создание файла само по себе не подключает AI: на этапе 3 приложение ещё не загружает эти настройки. На следующем этапе backend будет загружать их и выполнять два запроса. Ключи и доступ аккаунтов сейчас не проверены.

Стартовые кандидаты: [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini) поддерживает Responses и Structured Outputs; [NVIDIA Nemotron 3 Nano](https://docs.api.nvidia.com/nim/reference/nvidia-nemotron-3-nano-30b-a3b-infer) доступен в документации hosted NIM. Это не подтверждение доступа конкретного аккаунта или качества русского языка: оба проверяются реальными вызовами, прежде чем считать AI готовым. Серверный общий шаблон `.env.example` остаётся без ключей и выбранных моделей.

## Оценка оставшихся двух часов

Рабочая оценка до полного локального MVP: 90–110 минут при действующих ключах и доступных моделях. Отсчёт лимита в этой сессии — примерно 15:49 Алматы 23 сентября 2026; дедлайн около 17:49.

| Оставшаяся работа | Бюджет |
|---|---:|
| Подготовка настроек и доступ к двум API | 10 минут |
| AI backend: факты, два адаптера, валидация, кеш, таймауты | 30 минут |
| Справка OpenAI и рецензия NVIDIA в интерфейсе | 20 минут |
| Ошибки и реальные разборы 5–6 разных узлов | 25 минут |
| Финальные документы, push, репетиция демо | 20 минут |
| Резерв | 15 минут |

В срок входит локальное демо с обоими провайдерами. Новый дизайн, свободный чат, обучение моделей и облачный запуск не добавляем. Ошибки доступа к API могут сдвинуть оценку; не считать fallback успешной проверкой обоих провайдеров.
