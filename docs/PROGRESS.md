# Fusion: текущее состояние — этап 2 завершён

Реализован отдельный расчётный модуль. Первый этап сохранён. Следующий этап — API результатов и интерактивный граф; OpenAI/NVIDIA пока не подключались.

## Что добавлено

- `backend/analysis_config.py`: именованные пороги и параметры.
- `backend/features.py`: направленный граф всех узлов, суммы и счётчики, PageRank, ограниченная достижимость от seed, корректная сумма встречных весов для проекции.
- `backend/roles.py`: приоритет правил шести ролей, числовые evidence, эвристическая поддержка роли, восстанавливаемый из слагаемых приоритет.
- `backend/pipeline.py`: аудит → расчёт → проверка контрактов → три CSV и отчёт запуска одной командой, без API.
- `backend/tests/test_pipeline.py`: 14 содержательных проверок правил/графов/выгрузок.
- `docs/METHODOLOGY.md`: условия каждого правила, пороги, формулы скоров, ограничения и воспроизводимость.

## Фактическая проверка

Команда: `.venv/bin/python -m backend.pipeline` из корня проекта.

- Полный процесс с запуском интерпретатора и импортами: **1.37 с** (`/usr/bin/time -p`); внутреннее время с аудитом, расчётом и подготовкой CSV: **0.417 с**. Внутренний таймер снимается перед окончательной записью отчёта и заменой выходных файлов; для полного времени используем измерение процесса.
- Аудит входа: **34/34**; входные SHA-256 перепроверены перед публикацией выгрузок.
- `nodes_roles.csv`: **2248** строк; `clusters.csv`: **88**; `top_nodes.csv`: **20**.
- Полный граф: **35** слабосвязных компонент, **19** изолированных seed; ни один узел не потерян.
- Все **444** узла границы depth=4 отмечены `truncated_by_depth`; роль peripheral, не terminal.
- Роли: consolidator **95**, coordinator **18**, distributor **61**, transit **67**, terminal **1034**, peripheral **973**. Это гипотезы по правилам, не измерение истинных ролей.
- Все **26/26** тестов backend успешны. Включены реальные API-тесты через TestClient, мотивы ролей, защита больших ID, точные кластеры/суммы, ограниченная seed-достижимость, перестановка строк, повторный побайтно идентичный расчёт CSV и маленький валидный датасет из трёх узлов.
- Ошибка агрегатов в тесте останавливает расчёт и сохраняет прежнюю успешную выгрузку. Подтверждение актуальности — новый успешный run_report, а не само наличие CSV.
- Реальные parquet и starter совпадают с исходным MANIFEST. Файлы результата локальные, Git их игнорирует.

## Ограничения этого этапа

Разметки нет, качество классификации на истинных ролях не измерено. Terminal — только кандидат внутри наблюдаемой сети до четвёртого колена. Seed-входы неполны; коэффициент out/in для них не используется в ролях. Louvain не доказывает общность деятельности. Временные паттерны не рассчитаны, поэтому транзит — гипотеза по суммам, не утверждение о скорости перевода. Полные определения — в METHODOLOGY.md.

На странице Fusion пока остаётся сводка первого этапа: API ролей, интерактивный граф, поиск, карточка и скачивание CSV из браузера относятся к следующему этапу. Frontend не изменялся, его сборка и браузерная проверка в этом этапе повторно не запускались. Новые расчёты пока проверены через CLI и тесты, не через UI. Ключи не читались, внешних API-вызовов не было. Запуск на чистой машине не повторялся.

TestClient выводит прежнее неблокирующее предупреждение Starlette/httpx; тесты проходят. Список точных версий, параметры и SHA-256 результатов — в `artifacts/run_report.json`.

## Ограничения и противоречия материалов

- В графе всех входных узлов **35 компонент**, а **16** относится к графу только по рёбрам. Вне крупнейшей компоненты **371** узел с изолированными и **352** без них. Все **19 изолированных seed** учитываются аудитом и размером сводки.
- В ТЗ `out > in` указано для **354** узлов; это верно при `in > 0`. Всего таких узлов **377**, ещё 23 имеют нулевой наблюдаемый вход. Это не полный баланс счетов.
- Оборот **365890012.01 KZT** соответствует округлённому значению ТЗ. **97** повторных строк не считаются ошибками без `transaction_id` и не удаляются.
- **444** узла depth=4 без исходящих находятся на границе наблюдения. Это не доказательство роли terminal. Для seed входящие неполны; роли пока не назначаются.
- Восемь сообществ из описания не являются целевым числом кластеров. Разметки ролей нет; будущие скоры будут эвристическими, а не вероятностями виновности.
- AI в исходном кейсе опционален; оба провайдера обязательны в согласованном будущем сценарии Fusion. На первый этап это требование не переносится.

## Что осталось

Блокирующих проблем первого этапа не обнаружено. TestClient выводит неблокирующее предупреждение Starlette об устаревающем использовании `httpx`; текущие тесты и зависимости исправны. Миграция тестового HTTP-клиента в эту проверку не включалась.

Отдельно не проверены браузерная консоль, мобильные размеры экрана, принудительный 10-секундный таймаут и невалидный JSON в UI. Обработка этих ошибок видна в коде, но не отмечается как пройденный браузерный тест. Состояние загрузки реализовано; искусственная задержка для его отдельной визуальной проверки не создавалась. Установка с нуля на другой машине также не повторялась.

Следующий этап — только после отдельного запроса: расчётный модуль с графом всех узлов, числовыми признаками, документированными правилами шести ролей, кластерами, приоритетом, тремя CSV и содержательными проверками на синтетических графах. Потребуются имеющиеся локальные parquet и установленное окружение; ключи API для расчётов не нужны. После расчёта — графический интерфейс с поиском, карточкой и выгрузкой; далее отдельный AI-этап по [AI_DESIGN.md](AI_DESIGN.md).

Итоговые роли, кластеры, приоритеты, CSV, графический поиск и AI-разбор сейчас не реализованы. Фиктивные результаты не создавались; полный пересчёт будущего MVP за пять минут ещё не измерялся.
