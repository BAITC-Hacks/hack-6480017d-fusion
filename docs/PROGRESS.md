# Предыдущий этап: полные потоки и объяснение приоритета

23 сентября 2026. Закрыты P0 из аудита и следующего уточнения пользователя. Основной сценарий — выбор кандидата, денежные связи, пять оснований приоритета и ограничения — работает без LLM. Роли, формула priority, параметры кластеризации и обязательные CSV не менялись. Betweenness отложена в P2, NVIDIA остаётся выключенной.

## Что завершено

- Полные входящие/исходящие пары выбранного gid: точные кликабельные ID, суммы KZT до двух знаков, n_tx, итоги и число контрагентов. Таблица раскрывается под графом и прокручивается отдельно; лимит графа не сокращает список.
- Аналитический приоритет стал основным скором карточки. Видны место среди всех участников, пять уже взвешенных вкладов, база × множитель = результат и раскрываемое why. Role score подписан «Выраженность признаков роли» и не называется вероятностью.
- Статусы наблюдаемости: «Не обрезан на depth=4», «Граница depth=4», «Нет наблюдаемых связей». Для границы объясняется снижение множителем 0,5, для изолята — обнуление, для seed — неполный вход. Normal не обещает полного баланса.
- Сводка кластера: размер, число seed, сумма внутренних переводов, гипотеза и пять приоритетных GID с переходом. Сумма не включает внешние связи кластера.
- Desktop-карточка ограничена по высоте и прокручивается отдельно; при смене участника прокрутка сбрасывается. AI остаётся в отдельном широком окне. README и трёхминутное демо актуализированы.

## Что работает

- При запуске backend аудит и один расчёт создают общий снимок в памяти. API не читает старые artifacts и не записывает туда файлы. После замены parquet нужен перезапуск backend.

- Выбор кластера, окраска по ролям/кластерам, масштаб и вписывание; список узлов под графом доступен с клавиатуры. Размер узла соответствует приоритету, стрелки — направлению, ромб — границе выгрузки, двойной контур — seed.
