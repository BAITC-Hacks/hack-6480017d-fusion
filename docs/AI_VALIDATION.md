# Проверка AI в Fusion

Проверено 23 сентября 2026. Текущий сценарий — **OpenAI**, NVIDIA выключена по решению пользователя. Последний полный прогон: **6/6 реальных успешных ответов** без кеша, модель `gpt-5.4-mini-2026-03-17`, reasoning `low`, промпт `fusion-ai-v5`, пакет фактов версии 2. Это проверка работы и объяснений на примерах, не измерение accuracy ролей.

Задержка вызова OpenAI: **3.83–7.70 с**, медиана **4.42 с**. Провайдер сообщил **19,537 токенов суммарно** за эти шесть запросов (вход + выход, включая рассуждение). Это не весь расход диагностических прогонов и не точная стоимость в долларах.

## Что проверено

- Все ответы прошли строгую схему, проверку ссылок и посторонних ID. Схема генерации дополнительно ограничивает evidence_id реальным пакетом.
- Для всех шести NVIDIA получила `skipped` при `reviewer_enabled=false`: запросов к ней в этом прогоне нет. Fallback не использовался.
- Числовые признаки и направления связей доступны отдельно от текста модели. Ограничения выгрузки выводятся локально независимо от ответа.
- Unit-тесты проверяют неизменность рассчитанных ролей и CSV после AI-вызовов, кеш, ошибки, таймауты, отмену и отсутствие скрытых повторов.
- Браузерная проверка: отдельное окно разбора, реальный кеш, переход к факту, Escape, возврат фокуса; на ширине 390 px отсутствует горизонтальное переполнение.

## Найденные ограничения и исправления

В первом прогоне один ответ для изолированного seed был отклонён валидатором; повторный диагностический запрос прошёл, точная причина первого отказа без сохранённого отклонённого текста не установлена. Затем генерация ограничена enum допустимых ссылок. В ранних текстах встречались неверные числа контрагентов, лишние оговорки и слишком сильное прочтение границы; уточнены промпт и подпись факта. Последний прогон снова выполнен целиком после этих изменений.

Остаются интерпретационные формулировки, требующие аналитика, например «затем» не доказывает временную последовательность, а описание связующего узла не устанавливает организаторство. Правильная ссылка не гарантирует правильный вывод. Это ограниченная ручная сверка, не независимая банковская экспертиза и не статистическая оценка качества. Улучшение точности ролей от LLM не заявляется.

Предыдущая NVIDIA-модель вернула HTTP 410, доступный model ID с текущим ключом — HTTP 401. Успешных реальных ответов NVIDIA не было. Её необязательный адаптер проверен подставными ответами и выключен в демонстрации.

## Воспроизведение

При запущенном Fusion и настроенном серверном ключе:

```bash
.venv/bin/python -m backend.validate_ai --limit 6
```

Команда делает новые платные запросы и останавливается на первом сбое. Полный отчёт, исходные пакеты, ответы, времена и токены сохраняются локально в `artifacts/ai_validation.json`; файл не добавляется в Git. После нового запуска нужна новая ручная сверка. Результат одного прогона не гарантирует поведение модели в следующем.
