# Fusion: демо на 3 минуты

Цель: ответить «кого проверять первым и почему», сохранив видимость ограничений данных. Все примеры ниже выбраны из текущего локального расчёта, а не зашиты в алгоритм. GID копировать целиком как строку.

## Перед показом

- Открыть приложение: http://127.0.0.1:5173. Оставить оба сервера включёнными.
- Выполнить полный расчёт из корня проекта: `.venv/bin/python -m backend.pipeline`. Три CSV появятся в `artifacts/`.
- Проверить AI-разбор на шести примерах ниже. Реальный ответ OpenAI подтверждать по его статусу. NVIDIA в текущем сценарии отключена и не вызывается. Эти примеры сами по себе не подтверждают доступность API или качество ответов.
- Для трёхминутного показа допустимы заранее полученные реальные ответы из кеша: прямо показать отметку кеша. Не выдавать локальную справку за ответ модели.

## Шесть узлов для проверки AI и запасных вопросов

| Пример | GID (строка) | Рассчитанные признаки и что проверить в ответах |
|---|---|---|
| Кандидат в посредники | `100000003635170100` | `transit`, depth=1; 3 входящих / 4 исходящих контрагента; 268 500 / 253 500 KZT. Нельзя утверждать быстрый перевод, фактический баланс или доказанное посредничество только по out/in. |
| Наблюдаемый источник переводов | `100000007747786100` | seed, depth=0, `distributor`; 0 / 31 контрагент; 0 / 4 238 009,40 KZT; 35 исходящих переводов. Нулевой видимый вход у seed объясняется неполной выборкой и не означает создание денег или отсутствие доходов. |
| Кандидат в получатели | `100000006755850100` | `terminal`, depth=2; 1 / 0 контрагентов; вход 443 475,80 KZT. Нельзя заявлять, что деньги точно остались: внебанковские и исключённые переводы не наблюдаются. |
| Изолированный seed | `100000000456947100` | `peripheral`, depth=0; 0 связей, приоритет 0. Узел сохранён в результатах. Отсутствие связей не доказывает отсутствие активности или нарушения. |
| Связующий узел на третьем колене | `100000004603109100` | `coordinator`, depth=3; 3 / 2 контрагента; 2 730 000 / 400 000 KZT; достижим от 2 seed. Это структурная гипотеза, не установленный организатор. Depth=3 сам по себе не является границей depth=4. |
| Граница наблюдения | `100000008175078100` | `peripheral`, depth=4; 1 / 0 контрагентов; вход 1 846 711 KZT. Ноль исходящих здесь не основание для `terminal` или вывода «деньги осели». |

Для каждого AI-разбора проверить ссылки на факты, отсутствие придуманных GID и атрибутов клиента, отражение ограничений, русский язык и задержку. Это проверка объяснений на примерах, а не измерение точности ролей: эталонной разметки нет.

## Если интернет или API подвели

Продолжить показ графа, числовых признаков, правил и CSV. При ошибке OpenAI показать помеченную локальную справку и честно сказать, что новый ответ модели не получен. Отсутствие отключённой NVIDIA не является ошибкой текущего сценария.

Общие ограничения: июль 2026 года, только внутрибанковские переводы от 5 000 KZT, обход исходящих до четырёх колен, неполный вход seed, отсутствие остатков и внешних потоков. Роли и скоры — эвристики для проверки аналитиком, не вероятность виновности.
