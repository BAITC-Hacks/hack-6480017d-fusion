# Fusion: демо на 3 минуты

Цель: ответить «кого проверять первым и почему», сохранив видимость ограничений данных. Все примеры ниже выбраны из текущего локального расчёта, а не зашиты в алгоритм. GID копировать целиком как строку.

## Перед показом

- Открыть приложение: http://127.0.0.1:5173. Оставить оба сервера включёнными.
- Выполнить полный расчёт из корня проекта: `.venv/bin/python -m backend.pipeline`. Три CSV появятся в `artifacts/`.
- Основной показ проходит без вызова LLM: приоритет, потоки, наблюдаемость, кластер и CSV. Шесть реальных AI-справок уже проверены, протокол — [AI_VALIDATION.md](AI_VALIDATION.md); не тратить время на повторный платный прогон без изменений интеграции.
- OpenAI — запасной пример по вопросу жюри. Если используется ранее полученный ответ, прямо показать отметку кеша. Не выдавать локальную справку за ответ модели. NVIDIA отключена.

## Формулировки для защиты

- **Priority** — порядок аналитической проверки при текущих признаках и весах; не вероятность риска/участия.
- **Role strength** — выраженность признаков выбранного правила; не confidence probability, значения разных ролей не калиброваны между собой.
- **Наблюдаемость** — отдельное ограничение данных. «Не обрезан depth=4» не означает полного баланса; вход seed, внешние и мелкие переводы остаются неполными.
- У ролей могут пересекаться признаки. Выбирается одна основная роль по документированному порядку: например, 45 узлов подходят одновременно под consolidator и terminal, но получают более информативную гипотезу консолидации.
- Поиск транзита для запасного вопроса: `100000003635170100`, вход/выход 268 500 / 253 500 KZT. Out/in не устанавливает время удержания денег.
- Второго ранжирования по betweenness в основном сценарии нет; текущая формула сохранена.

Для каждого AI-разбора проверить ссылки на факты, отсутствие придуманных GID и атрибутов клиента, отражение ограничений, русский язык и задержку. Это проверка объяснений на примерах, а не измерение точности ролей: эталонной разметки нет.

## Если интернет или API подвели

Продолжить показ графа, числовых признаков, правил и CSV. При ошибке OpenAI показать помеченную локальную справку и честно сказать, что новый ответ модели не получен. Отсутствие отключённой NVIDIA не является ошибкой текущего сценария.

Общие ограничения: июль 2026 года, только внутрибанковские переводы от 5 000 KZT, обход исходящих до четырёх колен, неполный вход seed, отсутствие остатков и внешних потоков. Роли и скоры — эвристики для проверки аналитиком, не вероятность виновности.
