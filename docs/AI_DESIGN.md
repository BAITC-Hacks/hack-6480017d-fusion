# Fusion: объяснение рассчитанных фактов

## Действующий сценарий

По решению пользователя от 23 сентября 2026 MVP использует **OpenAI**. Модель — `gpt-5.4-mini`, уровень рассуждения `low`. NVIDIA отключена по умолчанию: текущий ключ был отклонён HTTP 401; прежний model ID также возвращал HTTP 410. Это не считается успешной интеграционной проверкой NVIDIA. Адаптер сохранён как необязательная возможность, которая включается только `NVIDIA_ENABLED=true`.

Граф, роли, скоры, кластеры и три CSV рассчитываются локально Python. AI объясняет наблюдаемую структуру, но не назначает роли, не меняет скоры и не принимает решения об участниках. Гипотеза модели и правильный JSON не доказывают истинность вывода.

## Путь пользователя

1. Выбрать участника в графе, топ-листе или найти по полному ID.
2. Нажать «AI-разбор»: открывается отдельное широкое окно с собственным прокручиванием; карточка сохраняет компактный размер.
3. Backend собирает пакет одного узла: 24 факта, максимум 8 направленных связей, период и ограничения. Каждый факт имеет `evidence_id` и источник. Все `gid/src/dst` — точные строки.
4. OpenAI получает только этот пакет и возвращает `hypothesis`, `claims[{claim_id,text,evidence_ids}]`, `limitations`, `next_checks`. Отказ или неполный ответ не выдаются за готовую справку.
5. Backend проверяет строгую схему, длины, ссылки и посторонние длинные ID. Интерфейс показывает справку, реальные модель/время/токены и переходы к фактам. Ограничения исходных данных дополнительно выводятся из локального расчёта независимо от модели.
6. Повторный разбор использует кеш. «Обновить · новый запрос» явно запрашивает новый ответ. Ошибка API оставляет доступными граф, числовую карточку и CSV; локальная справка имеет собственную маркировку и не называется ответом OpenAI.

## Контракт и ограничения

- `ai_evidence.py`: пакет с источниками, SHA входных parquet и версией правил. `total_neighbors/returned_neighbors` считают уникальных контрагентов, а флаг сокращения относится к отобранным рёбрам. Отправки всего parquet нет.
- `ai_models.py`: Pydantic со строгими типами и запретом дополнительных полей, ограничениями длины и проверкой `evidence_id/claim_id`. Это структурная валидация, не автоматическое доказательство содержательной корректности.
- `ai_providers.py`: OpenAI Responses с JSON Schema и `store=false`; HTTPX без повторов и редиректов. Таймаут каждого запроса 20 секунд, до 100 КБ входа/ответа, для GPT-5.4 mini до 3000 выходных токенов, включая рассуждение. Секреты, заголовки авторизации и тела ошибок провайдера не выводятся.
- `ai_service.py`: максимум 2 параллельных разбора, до 128 задач, кеш до 256 успешных результатов на 1 час в памяти. Перезапуск очищает кеш. Ключ зависит от пакета, данных, правил, моделей, режима рецензии, промптов, схем и параметров генерации. Ошибки и fallback не кешируются как успех.
- Нормальный разбор без кеша — **один вызов OpenAI**. Повторный клик во время работы присоединяется к той же задаче. Нет скрытых повторов, циклов агентов или дополнительной генерации для исправления JSON.
- POST `/api/ai/analyses` принимает `{gid: string, refresh: boolean}` и сразу возвращает 202 с задачей. GET `/api/ai/analyses/{job_id}` возвращает прогресс. GET `/api/ai/status` показывает публичные настройки и `reviewer_enabled`; наличие ключа не подтверждает его действительность.
- Интерфейс опрашивает задачу раз в 800 мс; через 60 секунд предлагает прочитать ту же задачу. Закрытие окна сохраняет результат; выбор другого узла отменяет ожидание клиента, но не запускает ещё один платный запрос.

## Необязательная NVIDIA

Только при `NVIDIA_ENABLED=true` валидная справка OpenAI и тот же пакет передаются NVIDIA hosted NIM. Результат — `issues`, `alternative_explanations`, `missing_information`. Замечания показываются отдельно; согласие моделей не является подтверждением гипотезы. Максимум два последовательных вызова и 45 секунд суммарно. При ошибке OpenAI рецензент не вызывается; при ошибке NVIDIA справка OpenAI сохраняется с честным предупреждением. Рецензия не меняет исходный текст, роль, скор или CSV.

Актуальный Nano ID `nvidia/nemotron-nano-3-30b-a3b` подтверждён публичным каталогом NVIDIA. Старое имя автоматически переводится в актуальное при загрузке конфигурации без изменения `.env`. Содержательная работа этого адаптера проверена только на подставных ответах: действующий ключ для реального успешного вызова не получен, рецензия исключена из обязательного демо.

## Проверка

Обычные unit-тесты не используют платные API. Они проверяют отказ, таймаут, ошибочный JSON, неизвестные ссылки, точность ID, кеш, повторные клики, частичный результат, отмену, отключённую NVIDIA и неизменность расчётов/CSV.

`.venv/bin/python -m backend.validate_ai` явно выполняет реальные запросы на 6 узлах, включая seed с неполным входом, границу depth=4 и изолированный seed; останавливается на первом сбое. Полные ответы сохраняются локально в игнорируемый `artifacts/ai_validation.json`. Ручная оценка интерпретаций и фактические задержки — в [AI_VALIDATION.md](AI_VALIDATION.md). Это проверка объяснений, а не измерение точности классификации: эталонной разметки ролей нет.

## Документация API

- [GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini): Responses, Structured Outputs и поддерживаемые уровни рассуждения.
- [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs): строгая схема, отказы и неполные ответы.
- [NVIDIA API Catalog](https://build.nvidia.com): необязательный hosted API; ключ Brev не подменяет ключ API Catalog.
