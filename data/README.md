# Исходные данные Fusion

В репозиторий включены три оригинальных файла из комплекта организаторов:

- nodes.parquet — 2248 узлов;
- edges.parquet — 3119 рёбер;
- transactions.parquet — 4840 переводов.

После клонирования они уже находятся в этой папке; копировать или заменять их не нужно. Другой набор загружается через кнопку «Данные» в интерфейсе и не изменяет эти оригиналы. API-ключи здесь не хранить и не публиковать. После установки зависимостей проверка: `.venv/bin/python -m backend.audit` из корня проекта.
