# Локальные данные Fusion

Для работы положите сюда три файла из комплекта организаторов:

- nodes.parquet — 2248 узлов;
- edges.parquet — 3119 рёбер;
- transactions.parquet — 4840 переводов.

Parquet исключены из Git; после clone их нужно отдельно скопировать из хакатонного комплекта. API-ключи здесь не хранить. После установки зависимостей проверка: `.venv/bin/python -m backend.audit` из корня проекта.
