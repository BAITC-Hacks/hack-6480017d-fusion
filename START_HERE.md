# Fusion — начать здесь

Fusion — локальный проект финансового трека HackAlem AI. Первые два этапа реализованы: аудит данных, backend, экран сводки и отдельный расчёт ролей/кластеров/приоритета с CSV. Текущий статус и результаты повторной проверки — в [docs/PROGRESS.md](docs/PROGRESS.md).

1. Откройте существующую папку Fusion. Не создавайте вложенную копию и не повторяйте создание каркаса. Подключение напарника описано в [docs/COLLABORATION.md](docs/COLLABORATION.md).
2. Проверьте наличие трёх исходных parquet в `data/`: они не входят в Git и после clone копируются отдельно из комплекта организаторов.
3. Установите локальные зависимости и запустите приложение по командам из [README.md](README.md). Если `.venv` и `frontend/node_modules` уже установлены, переустановка не нужна.
4. Перед следующим заданием прочитайте [AGENTS.md](AGENTS.md) и [docs/PROGRESS.md](docs/PROGRESS.md). `prompts/01_START.md` сохраняет требования первого этапа; второй этап уже выполнен, следующий — интерактивный граф.

Для аудита, расчётного модуля и сводки API-ключи не нужны. Серверный шаблон будущего AI-этапа — `backend/.env.example`; при подключении AI настройте `backend/.env` локально по [docs/AI_DESIGN.md](docs/AI_DESIGN.md), сохранив уже существующий файл. Не отправляйте ключи в чат или Git. Авторизация Codex и ключи приложения настраиваются отдельно.

## Что внутри

- backend/ — аудит, API сводки и расчётный модуль; frontend/ — экран сводки.
- docs/METHODOLOGY.md — формальные правила ролей, скоры и кластеры.
- artifacts/ — результаты команды `.venv/bin/python -m backend.pipeline` (локально, вне Git).
- data/ — место для трёх исходных parquet-файлов финансового трека, без изменений.
- docs/DATA_AUDIT.md и docs/PROGRESS.md — пересчитанный аудит и статус проверок.
- docs/case.md — полное исходное ТЗ организаторов.
- docs/dataset.md — исходное описание датасета.
- docs/DATA_NOTES.md — результаты предварительной проверки и ловушки данных.
- docs/PLAN.md — границы MVP и последовательность работы.
- docs/AI_DESIGN.md — обязательное использование обоих API в AI-разборе: аналитик и рецензент.
- prompts/UPDATE_TWO_PROVIDERS.md — сообщение для Codex, если работа по старому комплекту уже началась.
- starter/ — исходный код организаторов, без изменений; это незавершённый пример, не готовое решение.
- AGENTS.md — рабочие инструкции для Codex в этом проекте.
- prompts/01_START.md — первый промпт для запуска работы.
- backend/.env.example и .gitignore — серверный шаблон настройки и исключения Git.
- MANIFEST.json — исторические контрольные суммы исходного комплекта, не текущего приложения. Для неизменённых data/ и starter/ они подходят; рабочие документы с тех пор обновлялись, а шаблон конфигурации перенесён в backend/.

Исходные данные предназначены для хакатона. `data/*.parquet` исключены из Git; для сдачи следуйте правилам организаторов и обеспечьте жюри доступ к файлам.
