# Fusion — начать здесь

Это стартовый комплект для финансового трека HackAlem AI. Приложение ещё не реализовано; его собираем по этапам в Codex.

1. Распакуйте Fusion.zip. Откройте именно папку Fusion в Visual Studio Code через File → Open Folder.
2. Откройте расширение Codex и войдите через свою подписку ChatGPT.
3. Откройте prompts/01_START.md, скопируйте весь текст в новый диалог Codex и отправьте.
4. Codex проверит данные, создаст каркас проекта и запустит минимальный backend и frontend. По окончании сохраните его отчёт для следующего промпта.

API-ключи на первом этапе не нужны. Когда дойдём до AI-разбора, скопируйте .env.example в .env и впишите оба API-ключа вручную: OpenAI и NVIDIA. Не отправляйте ключ в чат. Авторизация Codex через подписку и ключ для приложения настраиваются отдельно.

## Что внутри

- data/ — три исходных parquet-файла финансового трека, без изменений.
- docs/case.md — полное исходное ТЗ организаторов.
- docs/dataset.md — исходное описание датасета.
- docs/DATA_NOTES.md — результаты предварительной проверки и ловушки данных.
- docs/PLAN.md — границы MVP и последовательность работы.
- docs/AI_DESIGN.md — обязательное использование обоих API в AI-разборе: аналитик и рецензент.
- prompts/UPDATE_TWO_PROVIDERS.md — сообщение для Codex, если работа по старому комплекту уже началась.
- starter/ — исходный код организаторов, без изменений; это незавершённый пример, не готовое решение.
- AGENTS.md — рабочие инструкции для Codex в этом проекте.
- prompts/01_START.md — первый промпт для запуска работы.
- .env.example и .gitignore — шаблон настройки и исключения Git.
- MANIFEST.json — контрольные суммы файлов комплекта, кроме самого манифеста.

Исходные данные предназначены для хакатона. data/ исключена из Git по умолчанию; для сдачи следуйте правилам организаторов и обеспечьте жюри доступ к файлам.
