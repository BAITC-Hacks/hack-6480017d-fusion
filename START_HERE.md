# Fusion — начать здесь

Fusion помогает аналитику выбрать приоритетных участников сети переводов и проверить основания на графе. Расчёт, поиск, карточки и три CSV работают локально; OpenAI добавляет справку со ссылками на факты.

1. Откройте существующую папку проекта и [README.md](README.md): там описаны задача, стек, установка, запуск и проверка. Не создавайте вложенную копию и не повторяйте создание каркаса.
2. Оригинальные `nodes.parquet`, `edges.parquet` и `transactions.parquet` организаторов входят в репозиторий и после клонирования уже находятся в `data/`. Копировать или заменять их не нужно.
3. После установки зависимостей из README запустите из корня проекта:

```bash
.venv/bin/python scripts/run_local.py
```

Откройте [Fusion — http://127.0.0.1:5173](http://127.0.0.1:5173). Если серверы уже работают, проверить их без остановки можно командой `.venv/bin/python scripts/run_local.py --check`.

4. Для сохранения трёх CSV и отчёта в `artifacts/` выполните `.venv/bin/python -m backend.pipeline`. Команда не требует AI-ключей или сети после установки зависимостей. Для другого набора используйте «Данные» → три Parquet или ZIP → «Проверить и загрузить»: перезапуск не нужен. При ручной замене parquet в data/ перезапустите backend; если выбран загруженный набор, сначала верните исходные данные через интерфейс.
5. Настройте OpenAI в серверном `backend/.env` по README, сохранив существующий файл. В текущем сценарии используется один OpenAI; **NVIDIA отключена по умолчанию (`NVIDIA_ENABLED=false`) и не вызывается**. Реальные ключи не включайте в Git и frontend.
6. Проверьте приложение и подготовьте выступление по [docs/DEMO.md](docs/DEMO.md). Результаты проверок — [docs/PROGRESS.md](docs/PROGRESS.md) и [docs/AI_VALIDATION.md](docs/AI_VALIDATION.md); правила расчёта — [docs/METHODOLOGY.md](docs/METHODOLOGY.md).

Для продолжения разработки следуйте [AGENTS.md](AGENTS.md). Файлы `prompts/01_START.md` и `prompts/UPDATE_TWO_PROVIDERS.md` — исторические материалы, не актуальные задания для повторного запуска. `starter/` — неизменённый незавершённый пример организаторов. Совместная работа и Git — [docs/COLLABORATION.md](docs/COLLABORATION.md).
